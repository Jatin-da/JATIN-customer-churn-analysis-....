# Customer Churn Prediction & Advanced AI Analytics

## Project Description
This project demonstrates customer churn prediction using Python and machine learning.

## Technologies Used
- Python
- NumPy
- pandas
- Matplotlib
- scikit-learn
- Jupyter Notebook

## Project Files
- Jatin_Customer_Churn_Analysis.ipynb — Project code
- Jatin_ProjectReport.docx — Project report
- requirements.txt — Required Python libraries
- README.md — Project overview and instructions

## Dataset
The notebook uses synthetic demonstration data, not real customer data. Results are for educational purposes only.

## How to Run
1. Install Python.
2. Install the required libraries using `pip install -r requirements.txt`.
3. Open the notebook in Jupyter Notebook.
4. Run the notebook cells from top to bottom.
